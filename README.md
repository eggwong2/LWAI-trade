## 它是什么

- 一个跑在浏览器里的本地化高效看盘工具。
- 用 Pine 脚本（TradingView 同款语言）写指标。
- 数据来自新浪，免费，非实时（盘后/延时数据）。
- 指标是私有的，只有你自己能用。
- 大户追踪抱团股票+识别抱团票操盘交易痕迹

## 能做什么

- 画 A 股 K 线和识别十大股东。
- **多图布局**：默认左右两图（左日线、右周线）。
- **每个图独立切换周期**，互不影响。
- **拼音搜股**：输入首字母即可，比如 `gzmt` 找到贵州茅台。
- 加载自己写的 Pine 指标。
- 显示 LWAI 体系各种指标。
- 指标参数调整与指标模板（保存、应用、删除）。
- 保存/恢复整张图的状态，刷新不丢。
- 自动计算流通股本、总股本、流通占比等。
- 前复权处理（价格、分红、成交量都复权），历史价格更准确。
- **一键更新依赖**，自动备份上一个版本，出问题一键回滚。

## 怎么跑起来

1. 装依赖：

```bash
npm install
```

2. 启动开发服务器：

```bash
npm run dev
```

3. 浏览器会自动打开 `http://localhost:5173`。

Mac 用户也可以直接双击 `启动.command` 一键启动。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动网页 |
| `npm run update` | 一键更新依赖（先备份） |
| `npm run update -- --yes` | 跳过确认，直接更新 |
| `npm run rollback` | 还原到更新前的版本 |

## 怎么更新依赖

1. 在运行 `npm run dev` 的终端按 `Control + C` 停掉网页。
2. 运行：

```bash
npm run update
```

3. 看清列出的「旧版本 → 新版本」：
   - 小更新（如 `0.8.4 → 0.8.5`）：放心按 `y`。
   - 大版本（第一个数字变了，如 `8.x → 9.x`）：建议先按 `n`。
4. 更新后 `npm run dev`，测试网页、多图、拼音搜股、指标。
5. 有问题就运行 `npm run rollback`。

说明：

- 备份放在 `.backups/prev`，**只保留上一个版本**。
- 更新范围只含依赖包，不会改动自己写的代码。
- 安装失败或依赖检查失败时，脚本会自动回滚。

## 数据源说明

`SinaProvider`（sina-provider.js）负责：

- 抓取 K 线数据。
- 抓取股本信息（用于流通股本 / 总股本）。
- 处理分红配股，做前复权（含成交量复权）。
- 股票名单本地缓存（约 5000+ 只），减少重复请求。
- 做成数据插头，既可以用免费源，也可以换付费实时行情 API。
